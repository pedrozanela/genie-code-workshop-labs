# Genie Code Workshop Labs (pt-BR)

Material de treinamento hands-on sobre **Databricks Genie Code**, traduzido e adaptado para português brasileiro.

## Sobre

Este repositório contém os labs práticos do workshop de Genie Code, originalmente criados por **Barry Hodges** (Databricks Senior Solution Architect, New Zealand) e traduzidos para pt-BR por **Pedro Zanela**.

O material cobre as capacidades principais do Genie Code usando um workspace **Databricks Free Edition** — não é necessário licença paga.

## Labs incluídos

| Lab | Título | Descrição |
|-----|--------|-----------|
| Setup | Configuração do Workspace | Criar schema e preparar o ambiente |
| 1 | Primeiros Passos | Setup, modos (Chat vs Agent) e navegação |
| 2 | Análise Exploratória (EDA) | Agent Mode executando EDA autônoma |
| 3 | Otimização SQL | `/prettify`, `/doc`, `/optimize` e debug de erros |
| 4 | Lakeflow Designer | Pipeline ETL visual no-code |
| 5a/5b | Spark Declarative Pipelines | Pipeline medallion (Bronze → Silver → Gold) |
| 6a/6b | Dashboards AI/BI | Criação de dashboards por linguagem natural |
| 7a/7b | Machine Learning | Predição de preços com MLflow |
| 8 | Funções AI SQL | `ai_classify`, `ai_summarize`, `ai_query` |
| 9 | Genie Spaces | Interface de chat para stakeholders não-técnicos |
| 10 | Personalização | Agent Skills, Instructions e MCP |

> Os labs com sufixo **"b"** são versões auto-dirigidas — fornecem objetivo e restrições, mas deixam você conduzir os prompts.

## Pré-requisitos

- Conta [Databricks Free Edition](https://www.databricks.com/try-databricks) (gratuita)
- Navegador web moderno
- Nenhuma experiência prévia com Databricks é obrigatória (mas ajuda!)
